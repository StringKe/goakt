The **`jobs`** package provides at-least-once, crash-safe durable task execution on top of an `ActorSystem`. Due jobs are delivered as ordinary request/reply (`Ask`) messages to actors or grains, with the handler's outcome driving acknowledgment, retry with configurable backoff, and dead-lettering. It also provides first-class fan-out/fan-in: split a parent job into many child jobs distributed across the cluster, and aggregate their results back into a single reduce-step delivery once every child has completed.

<Note>
This is an embedded, actor-native primitive: no extra server to run, jobs delivered as actor/grain messages participating in the same supervision and cluster lifecycle as the rest of your `ActorSystem`. It targets teams that would otherwise stand up Asynq/River (with their own Redis/Postgres) just for durable background work.
</Note>

## Core concepts

- **`jobs.Job`** — a unit of durable work: target actor/grain name, serialized payload, retry policy, and lifecycle state.
- **`jobs.Store`** — the storage-agnostic persistence contract (`Enqueue`/`Lease`/`Ack`/`Nack`/`DeadLetter`, plus a read/admin surface). `jobs.NewMemoryStore()` is the built-in default; durable adapters (SQL, ...) can be implemented outside this package.
- **`jobs.Engine`** — binds a `Store` to an `ActorSystem`: polls for due jobs and delivers each one.
- **`jobs.Inspector`** — a read/admin surface over a `Store` for operator tooling.

## Defining and enqueuing a job

```go
import (
    "github.com/tochemey/goakt/v4/jobs"
)

store := jobs.NewMemoryStore()
engine, err := jobs.NewEngine(actorSystem, jobs.EngineConfig{
    Store: store,
})
if err != nil {
    return err
}
if err := engine.Start(ctx); err != nil {
    return err
}
defer engine.Stop(ctx)

job, err := jobs.NewJob("rewards", "reward-worker", &rewardspb.ComputeReward{AgentId: "agent-42"})
if err != nil {
    return err
}
if err := engine.Enqueue(ctx, job); err != nil {
    return err
}
```

`"reward-worker"` is resolved by name via `ActorSystem.ActorOf` at delivery time, so the job reaches whichever PID currently answers to that name — locally or, in cluster mode, anywhere in the cluster.

## The handler contract

A job's target actor receives the deserialized payload as an ordinary message, delivered via `Ask`. Its reply drives the outcome:

```go
func (a *RewardWorker) Receive(ctx *actor.ReceiveContext) {
    switch msg := ctx.Message().(type) {
    case *rewardspb.ComputeReward:
        reward, err := a.compute(msg.GetAgentId())
        if err != nil {
            // Reply with the error itself: this is how a handler explicitly
            // rejects a job (as opposed to a bug that hangs it until the
            // engine's AskTimeout elapses).
            ctx.Response(err)
            return
        }
        ctx.Response(&rewardspb.RewardComputed{Amount: reward})
    default:
        ctx.Unhandled()
    }
}
```

- Reply with anything other than an `error` value: the job is **Ack**'d.
- Reply with an `error` value, or never reply (the `Ask` times out), or the target cannot be resolved: the job is **Nack**'d and retried per its `RetryPolicy`, or moved to the dead-letter state once attempts are exhausted.

<Warning>
A worker that crashes mid-delivery never gets the chance to Ack or Nack. That is fine by design: its lease simply expires, and any `Engine` sharing the same `Store` (an inevitability in cluster mode, since every node runs its own `Engine`) reclaims and redelivers the job on a later poll. This is what makes delivery crash-safe by construction.
</Warning>

## Retry policies

```go
job, err := jobs.NewJob("rewards", "reward-worker", msg,
    jobs.WithRetryPolicy(jobs.ExponentialBackoff(time.Second, time.Minute, 8)))
```

| Constructor                                       | Behavior                                              |
|----------------------------------------------------|--------------------------------------------------------|
| `jobs.FixedBackoff(delay, maxAttempts)`             | Waits `delay` before every retry.                       |
| `jobs.LinearBackoff(base, maxDelay, maxAttempts)`   | Grows by `base` every retry (`base`, `2*base`, ...), capped at `maxDelay`. |
| `jobs.ExponentialBackoff(base, maxDelay, maxAttempts)` | Doubles every retry starting at `base`, capped at `maxDelay`. |

`jobs.DefaultRetryPolicy()` (exponential, 1s base, 1m cap, 5 attempts) applies when `NewJob` is called without `WithRetryPolicy`. Once `MaxAttempts` is reached, the job moves to the dead-letter state instead of retrying again.

## Fan-out / fan-in

Split a parent job into child jobs distributed across the cluster; once every child completes, the parent's target receives a `*jobs.FanInEnvelope` with every child's result, ordered by child index — the map/reduce shape needed for computations like "an agent's total downline rewards":

```go
parent, err := jobs.NewJob("rewards", "reward-aggregator", &rewardspb.AggregateRewards{})
if err != nil {
    return err
}

children := make([]*jobs.Job, len(downlineAgentIDs))
for i, agentID := range downlineAgentIDs {
    children[i], err = jobs.NewJob("rewards", "reward-worker", &rewardspb.ComputeReward{AgentId: agentID})
    if err != nil {
        return err
    }
}

if err := engine.FanOut(ctx, parent, children); err != nil {
    return err
}
```

Each child is delivered wherever the cluster happens to lease it — there is no requirement that a single node hosts every child. If any child is ultimately dead-lettered, the parent is dead-lettered too rather than reducing over a gap.

```go
func (a *RewardAggregator) Receive(ctx *actor.ReceiveContext) {
    switch msg := ctx.Message().(type) {
    case *jobs.FanInEnvelope: // alias for the internal wire type the engine delivers
        var total int64
        for _, result := range msg.GetResults() {
            if result.GetFailed() {
                ctx.Response(fmt.Errorf("child %d failed: %s", result.GetChildIndex(), result.GetError()))
                return
            }
            // decode result.GetPayload() the same way the child's own
            // response was serialized, then accumulate it.
        }
        ctx.Response(&rewardspb.RewardsAggregated{Total: total})
    default:
        ctx.Unhandled()
    }
}
```

## Inspecting jobs

```go
inspector := engine.Inspector()

// list dead-lettered jobs
deadLetters, err := inspector.List(ctx, jobs.Filter{States: []jobs.State{jobs.StateDeadLetter}})

// force a manual retry after fixing the underlying issue
err = inspector.Retry(ctx, jobID)

// operator dashboard: non-terminal job count per queue
depths, err := inspector.QueueDepths(ctx)
```

## Reference

| Type / method                                  | Purpose                                                                 |
|--------------------------------------------------|--------------------------------------------------------------------------|
| `jobs.NewJob(queue, targetName, message, opts...)` | Build a job ready for `Enqueue`/`FanOut`.                                |
| `jobs.NewMemoryStore()`                          | The built-in, process-local `Store`.                                    |
| `jobs.NewEngine(system, cfg)`                    | Bind a `Store` to an `ActorSystem`.                                     |
| `engine.Enqueue(ctx, job)`                       | Durably record a job for future delivery.                                |
| `engine.FanOut(ctx, parent, children)`           | Enqueue a fan-out parent and its children as a linked unit.              |
| `engine.Inspector()`                             | A read/admin surface (`List`, `Get`, `Retry`, `Delete`, `QueueDepths`).  |
| `jobs.WithRetryPolicy` / `WithDelay` / `WithID`  | `JobOption`s configuring a job built by `NewJob`.                        |
