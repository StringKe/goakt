**`ActorSystem.KV()`** exposes a narrow, cluster-scoped key/value registry and distributed lock backed by the same embedded engine (Olric) that GoAkt already uses internally to track actor and grain placement. It is a thin, deliberate exposure of primitives the framework relies on internally — not a new storage engine.

<Note>
This is a **registry for application metadata** — ownership records, idempotency/dedup keys, short-lived coordination locks — not a general-purpose cache. Reads are strongly consistent with respect to the cluster's configured write/read quorum, unlike the eventually-consistent [distributed data (CRDT)](/advanced/distributed-data) package.
</Note>

## When to use

- **Ownership records** — "which node/instance currently owns this logical entity"
- **Idempotency / dedup keys** — `PutIfAbsent` combined with a TTL doubles as a self-expiring seen-keys store
- **Short-lived coordination locks** — e.g. electing exactly one node to perform a task (issue a certificate, run a maintenance job)

For a general-purpose cache, use an external cache instead — the cluster registry is sized and tuned for small, cluster-scoped coordination state, not bulk data.

## Getting a Store

`KV()` requires cluster mode to be enabled (`WithCluster(...)`). It returns `ErrClusterDisabled` otherwise, and `ErrActorSystemNotStarted` if the actor system has not been started.

```go
store, err := system.KV()
if err != nil {
    // ErrActorSystemNotStarted or ErrClusterDisabled
    return err
}
```

## Get, Put, Delete

```go
import (
    "time"

    "github.com/tochemey/goakt/v4/kv"
)

// Put stores a value, optionally with a TTL.
_ = store.Put(ctx, "registry:widget", []byte("node-1"))
_ = store.Put(ctx, "session:abc", []byte("token"), kv.WithTTL(5*time.Minute))

// Get retrieves a value; returns kv.ErrKeyNotFound if absent or expired.
value, err := store.Get(ctx, "registry:widget")

// Delete removes a value; it is a no-op if the key does not exist.
_ = store.Delete(ctx, "registry:widget")
```

## PutIfAbsent

`PutIfAbsent` stores a value only if the key is not already present, returning `kv.ErrKeyExists` otherwise. This is the primitive for cluster-wide uniqueness checks — the same one GoAkt uses internally to guarantee a grain activates on exactly one node.

```go
err := store.PutIfAbsent(ctx, "dedup:msg-42", []byte("seen"), kv.WithTTL(time.Minute))
if errors.Is(err, kv.ErrKeyExists) {
    // another node (or a previous call) already processed this message
    return nil
}
```

## Distributed locks

`TryLock` makes a single, non-blocking attempt to acquire a lock: if another holder already owns the key, it returns `kv.ErrLockNotAcquired` immediately rather than waiting. The lock auto-expires after `ttl` even if `Unlock` is never called, so a crashed holder cannot wedge the key forever.

```go
lock, err := store.TryLock(ctx, "cert:example.com", 30*time.Second)
if errors.Is(err, kv.ErrLockNotAcquired) {
    // another node is already handling this
    return nil
}
if err != nil {
    return err
}
defer lock.Unlock(ctx)

// ... do the work only the lock holder should perform ...
```

`Unlock` returns `kv.ErrLockNotHeld` if the lock already expired or was already released.

<Warning>
`TryLock` never blocks waiting for the lock to free up. If you need retry-with-backoff semantics, loop and call `TryLock` again after a delay.
</Warning>

## Reference

| Method                                 | Purpose                                                          |
|-----------------------------------------|-------------------------------------------------------------------|
| `store.Get(ctx, key)`                   | Fetch a value; `kv.ErrKeyNotFound` if absent or expired.           |
| `store.Put(ctx, key, value, opts...)`   | Store a value, optionally with `kv.WithTTL(d)`.                    |
| `store.PutIfAbsent(ctx, key, value, opts...)` | Store only if absent; `kv.ErrKeyExists` otherwise.           |
| `store.Delete(ctx, key)`                | Remove a value; no-op if absent.                                   |
| `store.TryLock(ctx, key, ttl)`          | Non-blocking lock attempt; `kv.ErrLockNotAcquired` if already held. |
| `lock.Unlock(ctx)`                      | Release a lock; `kv.ErrLockNotHeld` if already released/expired.    |
